
# 🛍️ Online Retail Recommendation System

> A Machine Learning-based recommendation system that suggests similar products to customers using **Collaborative Filtering** and **Jaccard Similarity**. This project analyzes customer purchase behavior from an online retail dataset to generate personalized product recommendations.
