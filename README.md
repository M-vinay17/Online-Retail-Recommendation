# 🛍️ Online Retail Recommendation System

> A Machine Learning-based recommendation system that recommends similar
> products using **Collaborative Filtering** and **Jaccard Similarity**
> based on customer purchase history.

## 📌 Overview

This project analyzes customer transactions from an online retail store
and recommends similar products by identifying purchasing patterns. The
recommendation engine uses **Jaccard Similarity** to measure
relationships between products purchased by different customers.

## 🧠 Similarity Function

The project uses **Jaccard Similarity**:

    J(A,B) = |A ∩ B| / |A ∪ B|

A higher score indicates that two products are frequently purchased by
the same customers.
